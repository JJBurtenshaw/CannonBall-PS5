# CannonBall-PS5
A native PlayStation 5 homebrew port of CannonBall, the enhanced OutRun arcade engine.

CannonBall-PS5 brings Chris White's CannonBall engine to PlayStation 5 homebrew, aiming to deliver the classic arcade experience with modern enhancements and native DualSense support.

Project goals
- Native PS5 execution without Linux.
- Smooth 60 FPS gameplay.
- DualSense controller integration.
- PS5 dashboard integration through ShadowMountPlus.
- Persistent configuration and high scores.
- Simple installation and setup.

Current development status — November 2026
Experimental / In Development

The SDL-based port has successfully run on real PS5 hardware. Native PS5 packaging and dashboard launching have also been demonstrated using test applications. Full native integration is still underway.

Original project: Chris White's CannonBall ([https://github.com/djyt/cannonball](https://github.com/djyt/cannonball))
