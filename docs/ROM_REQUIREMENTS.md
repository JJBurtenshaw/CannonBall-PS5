# OutRun ROM requirements

CannonBall PS5 requires 31 compatible original
OutRun arcade ROM files for its standard configuration.

**ROM files are not included.**

Place your own legally obtained ROM files directly
inside `PPSA98537/roms/`.

Do not leave the files inside a ZIP archive or
place them inside a nested directory.
